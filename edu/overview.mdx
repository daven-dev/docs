교육앱을 만들고 Daven에 제출하는 개발자용 문서입니다.

**당신이 할 일:** MCP 키 발급 → 앱 제작·배포 → [Playground](https://daven.ai/playground) 검증·제출.  
교실 연결·실행은 Daven이 처리합니다. 브라우저에 API 키를 두지 마세요.

| 문서 | 내용 |
| --- | --- |
| [빠른 시작](/edu/quickstart) | 키 · 제작 · 배포 · 제출 |
| [MCP API](/edu/proxy-api) | 생성 proxy 엔드포인트 |
| [학생 제출](/edu/submissions) | LMS 제출 envelope (URL) |
| [연동 체크리스트](/edu/checklist) | 출시 전 점검 |
| [레퍼런스 앱](/edu/reference-app) | 시화 스튜디오 |

## 역할

| 구분 | 설명 |
| --- | --- |
| 교육앱 | 당신이 만드는 수업용 웹앱 |
| Daven Playground | 앱 검증·제출 |
| Classroom Hub (Edu) | 승인된 앱을 수업에서 사용 |
| Daven AI | 이미지·음성·음악 등 생성 |

## 원칙

- MCP 키는 서버에만 둡니다.
- Playground에서 검증한 뒤 Submit합니다.
- AI는 보조입니다. 학생 원문이 중심이어야 합니다.

AI 코딩 도구에 `@davenai/mcp`를 연결하면, 에이전트가 `daven_guidelines`를 따릅니다.
