## 복사할 파일

| 파일 | 역할 |
| --- | --- |
| `src/lib/daven-config.ts` | `session` / `proxy` 파싱, 기본 proxy |
| `src/lib/daven.ts` | 세션 헤더 + `davenFetch` |
| `src/app/page.tsx` (및 관련 UI) | 수업 플로우 예시 |

## 로컬 3프로세스

Hub API · Hub Web · 앱을 나란히 띄웁니다.

```bash
# 1) Hub API — :3001
cd dv-edu/apps/api && npm run start:dev

# 2) Hub Web — :3000 (또는 프로젝트 기본 포트)
cd dv-edu/apps/web && npm run dev

# 3) App — 예: :3010
cd dv_mcp/apps/sihwa_project && npm run dev
```

활동 URL에 앱 origin을 넣고, Edu에서 활동을 열면 `session`·`proxy`가 붙습니다.

<Tip>
  새 앱을 만들 때 UI는 바꿔도 됩니다. **config + fetch 레이어**만 그대로 가져가면 연동 시간이 가장 짧습니다.
</Tip>
