이 페이지는 **사람이 읽는 Quickstart가 아니라 에이전트 구현 스펙**입니다. 우선 `@davenai/mcp` 도구 **`daven_guidelines`**를 호출하세요 (`topic=edu_app`, 학생 제출 시 `topic=submission`). 모호하면 추측하지 말고 그 출력을 따르세요.

원문: [`llms.txt`](/edu/llms.txt) · Proxy: [`openapi.yaml`](/edu/openapi.yaml) · 제출: [`lms-openapi.yaml`](/edu/lms-openapi.yaml) · [`activity-submission.schema.json`](/edu/activity-submission.schema.json)

## MUST

1. HTTPS(또는 local) 웹앱을 Edu iframe에서 연다.
2. `URLSearchParams`로 `session`, `proxy`를 읽는다.
3. Daven 호출은 `{proxy}` base만 사용한다.
4. 매 요청에 `Authorization: Bearer {session}` **그리고** `X-Edu-Session: {session}`을 넣는다.
5. 응답 envelope를 파싱한다: `status === "success" | "error"`.
6. 프론트에 API 키 / MCP 시크릿을 넣지 않는다.

## MUST NOT

1. 브라우저에서 `daven.ai` / `app.daven.ai`를 직접 호출하지 않는다.
2. 팝업·top navigation을 Edu 기본 플로우에 필수로 두지 않는다.
3. 학생 원문을 AI 결과로 자동 덮어쓰지 않는다.

## Canonical client (copy)

```ts
const params = new URLSearchParams(location.search);
const session = params.get("session");
const proxy = (
  params.get("proxy") || "https://edu.daven.ai/api/v1/mcp-proxy"
).replace(/\/$/, "");

export async function davenFetch(path: string, init?: RequestInit) {
  const res = await fetch(
    `${proxy}${path.startsWith("/") ? path : `/${path}`}`,
    {
      ...init,
      headers: {
        Accept: "application/json",
        "Content-Type": "application/json",
        ...(session
          ? {
              Authorization: `Bearer ${session}`,
              "X-Edu-Session": session,
            }
          : {}),
        ...(init?.headers ?? {}),
      },
    },
  );
  const json = await res.json();
  if (!res.ok || json?.status === "error") {
    throw new Error(json?.error?.message || res.statusText);
  }
  return json;
}
```

## Acceptance (binary)

에이전트는 아래가 전부 true일 때만 “연동 완료”라고 보고합니다.

- [ ] `davenFetch("/api/account")` → HTTP 200, `status === "success"`
- [ ] 세션 헤더 제거 시 → 401
- [ ] DevTools Network에 Edu proxy host만 존재
- [ ] iframe sandbox에서 핵심 플로우 완료 가능
