목표: iframe 없이도 **session + proxy**로 account 호출이 성공하면 연동 스모크 통과입니다.

<Tip>
  코딩 에이전트라면 [에이전트 스펙](/edu/agent-spec)과 [`llms.txt`](/edu/llms.txt)를 먼저 넣고 이 Steps를 실행하세요.
</Tip>

<Steps>
  <Step title="앱 호스팅">
    HTTPS로 배포합니다 (예: Vercel). 로컬이면 `localhost`도 가능합니다.

    Hub iframe sandbox는 `allow-scripts allow-forms allow-same-origin`입니다. 팝업·top-level 리다이렉트에 의존하지 마세요.
  </Step>

  <Step title="쿼리 파싱">
    Edu가 붙이는 값을 읽습니다.

    ```ts
    const params = new URLSearchParams(window.location.search);
    const session = params.get("session"); // required in Edu
    const proxy =
      params.get("proxy") || "https://edu.daven.ai/api/v1/mcp-proxy";
    ```

    <AccordionGroup>
      <Accordion title="프로덕션 proxy">
        `https://edu.daven.ai/api/v1/mcp-proxy`
      </Accordion>
      <Accordion title="로컬 Hub API">
        `http://localhost:3001/api/v1/mcp-proxy`
      </Accordion>
    </AccordionGroup>
  </Step>

  <Step title="세션 헤더 클라이언트">
    <CodeGroup>

    ```ts daven.ts
    export async function davenFetch(
      proxy: string,
      session: string | null,
      path: string,
      init?: RequestInit,
    ) {
      const base = proxy.replace(/\/$/, "");
      const url = `${base}${path.startsWith("/") ? path : `/${path}`}`;
      const res = await fetch(url, {
        ...init,
        headers: {
          Accept: "application/json",
          "Content-Type": "application/json",
          ...(session
            ? {
                Authorization: `Bearer ${session}`,
                "X-Edu-Session": session,
              }
            : {}),
          ...(init?.headers ?? {}),
        },
      });
      const json = await res.json().catch(() => ({}));
      if (!res.ok) {
        throw new Error(json?.error?.message || res.statusText);
      }
      return json;
    }
    ```

    ```bash curl
    curl -sS "$PROXY/api/account" \
      -H "Authorization: Bearer $SESSION" \
      -H "X-Edu-Session: $SESSION"
    ```

    </CodeGroup>
  </Step>

  <Step title="스모크 테스트">
    ```ts
    const account = await davenFetch(proxy, session, "/api/account");
    // expect: account.status === "success"
    ```

    Hub 없이 검증하려면 Hub API를 띄우고, 개발용 세션 토큰으로 앱을 엽니다.

    ```bash
    # Hub API
    cd dv-edu/apps/api && npm run start:dev

    # App (별도 터미널)
    # 예: sihwa — http://localhost:3010
    ```
  </Step>

  <Step title="생성 루프">
    권장 순서:

    1. `POST /api/quote`
    2. `POST /api/media/create`
    3. `POST /api/media/get` 폴링
    4. 미리보기 / 다운로드

    상세 필드는 [Proxy API](/edu/proxy-api) · [OpenAPI](/edu/openapi.yaml)를 보세요.
  </Step>
</Steps>

## 완료 기준

| # | 통과 조건 |
| --- | --- |
| 1 | `GET {proxy}/api/account` → HTTP 200, `status === "success"` |
| 2 | 세션 없이 동일 호출 → **401** |
| 3 | Network에 **Edu proxy 호스트**만 보임 (`daven.ai` 직접 호출 없음) |
