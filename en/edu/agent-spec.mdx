## MUST

1. Host an HTTPS (or local) web app opened in the Edu iframe.
2. Read `session` and `proxy` via `URLSearchParams`.
3. Call Daven only against the `{proxy}` base.
4. Send `Authorization: Bearer {session}` **and** `X-Edu-Session: {session}` on every request.
5. Parse the envelope: `status === "success" | "error"`.
6. Never put API keys / MCP secrets in the frontend.

## MUST NOT

1. Call `daven.ai` / `app.daven.ai` directly from the browser.
2. Require popups or top-level navigation for the default Edu flow.
3. Auto-overwrite student-authored text with AI output.

## Canonical client (copy)

```ts
const params = new URLSearchParams(location.search);
const session = params.get("session");
const proxy = (
  params.get("proxy") || "https://edu.daven.ai/api/v1/mcp-proxy"
).replace(/\/$/, "");

export async function davenFetch(path: string, init?: RequestInit) {
  const res = await fetch(
    `${proxy}${path.startsWith("/") ? path : `/${path}`}`,
    {
      ...init,
      headers: {
        Accept: "application/json",
        "Content-Type": "application/json",
        ...(session
          ? {
              Authorization: `Bearer ${session}`,
              "X-Edu-Session": session,
            }
          : {}),
        ...(init?.headers ?? {}),
      },
    },
  );
  const json = await res.json();
  if (!res.ok || json?.status === "error") {
    throw new Error(json?.error?.message || res.statusText);
  }
  return json;
}
```
