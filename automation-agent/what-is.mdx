---
title: "자동화 에이전트란"
---

자동화 에이전트는 지정한 시간동안 일어났던, 실시간 정보 또는 일반 정보를 근간으로 내가 원하는 컨텐츠를 생성하는 기능입니다.

- 실시간 정보 기반 : 뉴스, 증시 소식 등등 실시간 정보에 기반한 데이터를 처리하여 내가 원하는 형태의 결과물을 만들어줍니다. ( 예 : 매일 만평 카툰, 미국 증시 뉴스 요약 신문 등등 )
- 일반 정보 기반 : 매일 영어 학습, 골프 레슨, 묵상을 위한 오늘의 명언 등 일반 정보에 기반한 데이터를 처리하여 내가 원하는 형태의 결과물을 만들어줍니다. ( 예: 매일 고급 비즈니스 영어표현 10개 노트, 오늘 태어난 위인들의 명언 쇼츠 )

자동화 에이전트는 반복되는 작업을 정해진 시간에 자동으로 작업 요청을 해서 결과물을 생성합니다. 

예)

- 내가 만든  캐릭터로 직장에서 일어날수 있는 다양한 에피소드 매일 아침 7시에 생성  : 웹툰
- 매일 아침 7시 세계 금융 뉴스를 지난 12시간동안 뉴스중에서 중요한 순으로 생성 : 인포그래픽 신문 형태
- 오늘 태어난 위인의 명언을 매일 저녁 9시에  숏폼으로 생성 : 숏폼으로 연재. 유튜브에도 업로드
- 매일 12시 정오에 내가 사는 동네 뉴스를 생성 : 웹 뉴스 스타일
