자동화 에이전트는 3가지 설정 항목이 있습니다.

- 일정 : 언제 실행할까요
- 데이터 수집 및 요약 : 어떻게 만들까요 ?
- 결과물 : 어떤 결과물을 만들까요 ?

만일 아침 7시마다 어제 저녁에 있었던 미국 증시 뉴스를 받아보고 싶으면

- 일정에 매일 아침 7시를 설정하고
- 데이터 수집 및 요약 : Prompt 에 지난 12시간동안 미국 증시 요약을 넣고, 고급 설정에서 참조할 자료등을 세팅합니다.

만일 저녁에 잠들기 전에 명상을 위한 명언을 듣고 싶으면

- 일정에 매일 저녁 9시를 설정하고
- 데이터 수집 및 요약 : Prompt 에 오늘 태어난 유명인의 명언 이라고 넣으면 됩니다.

1. 자동화 에이전트가 실행될 시간을 정합니다.

2. 어떤 데이터를 가지고 무슨 컨텐츠를 만들지를 설정합니다.

<Frame>
  ![Image](/images/image-31.png)
</Frame>

- 고급 세팅에서 실시간 정보 타입일 경우 \
  a. 검색언어 지정 ( 예를 들면 미국뉴스는 일본어로 검색하고, 일본뉴스는 일본어로 검색해야 더 많은 결과를 가지고 올수 있습니다)

  b. 검색할 시간 조건, 검색 항목 결과 참조 조건, 검색 결과 정리 조건, 화이트 리스트 등을 설정합니다.

  c. 이를 통해 뉴스, 증시 소식 등등 실시간 정보에 기반한 데이터를 처리하여 내가 원하는 형태의 결과물을 만들어줍니다. ( 예 : 매일 만평 카툰, 미국 증시 뉴스 요약 신문 등등 )
- 고급 세팅에서 일반 정보 타입일 경우

  검색이 필요없으므로 별도로 지정할 필요가 없습니다.

  매일 영어 학습, 골프 레슨, 묵상을 위한 오늘의 명언 등 일반 정보에 기반한 데이터를 처리하여 내가 원하는 형태의 결과물을 만들어줍니다. ( 예: 매일 고급 비즈니스 영어표현 10개 노트, 오늘 태어난 위인들의 명언 쇼츠 )
