<Info>
  오류가 발생한 모든 콘텐츠의 경우 토큰이 차감되지 않습니다.
</Info>

AI 콘텐츠 생성의 경우, 사용자의 입력 혹은 서버의 예기치 못한 오류로 콘텐츠 생성 오류가 발생할 수 있습니다. 선택한 AI의 모델에 따라 생성 가이드라인이 조금씩 다르므로 그 결과가 다를 수 있습니다.

### 다음을 포함하는 내용은 생성이 제한될 수 있습니다

- 포르노물 또는 과도한 노출
- 인종, 민족, 출신 국가, 종교, 심각한 질병이나 장애, 성별, 연령 또는 성적 취향을 근거로 집단을 공격하거나 인간성을 말살시키는 혐오스럽거나 매우 모욕적인 콘텐츠
- 노골적인 폭력 또는 유혈 사태
- 난동을 조장하고 미화하거나 위협하는 행위
- 불법 활동 또는 상품
- 자해 또는 자해 조장
- 미성년자 누드 또는 미성년자를 성적 대상으로 묘사
- Google Veo3 의 경우, 미성년자 사진 업로드 자체만으로 생성이 제한될 수 있습니다
- 테러 또는 폭력적 극단주의 조장
- 현실 세계에 유해한 왜곡, 사기 또는 기만적인 콘텐츠 유포
- 타인의 사적 정보
- Sora (OpenAI) 모델의 경우 실제 사람 (Photorealistic) 이미지를 첨부할 경우 생성이 제한 될 수 있습니다.
- 특정 IP (Intellectual Property) 나 카피라이트를 위반한 캐릭터나 오브젝트를 사용한 경우
- 특정 IP (Intellectual Property) 나 카피라이트를 위반 소지가 있는 캐릭터나 오브젝트를 사용한 경우
- 기타 각 AI 모델 제공사의 생성 정책에 위반된 경우

<Info>
  다음을 포함하는 내용은 생성이 제한될 수 있고, 이를 계속해서 위반 할 경우 다음과 같은 페널티가 주어질 수 있습니다\
  - 제공사의 검열에 따라 해당 ID 의 콘텐츠 생성이 지속적으로 느려질수도 있습니다\
  - 계정이 일시 정지 또는 영구 정지\
  \
  이는 대부분의 경우에 각 AI 모델 제공사가 판단하며, 서비스 제공자는 어떠한 책임이나 계정의 크레딧 환불 보상의 의무등 일체의 의무를 지지 않습니다. 무제한 사용자도 이 내용에 동의를 전제로 제공됨으로 간주합니다. 이 문제로 인해 계정이 일시 또는 영구 정지 될경우 멤버쉽에 취소에 대한 환불은 제공하지 않습니다.
</Info>

### 생성 오류 메시지

| 메시지 | 내용 |
| --- | --- |
| 서버가 불안정합니다. 잠시 후 다시시도해주세요 | 트래픽이 과도하게 발생하여 서버가 느려진 경우 발생하는 에러입니다. |
| This content may violate OpenAI's content policies. | OpenAI의 모델 (Sora, GPT Image) <br />의 가이드라인에 위반할 경우 발생하는 에러입니다. |
| Request blocked: The generation was halted during Google safety review. <br />You may try adjusting the prompt and try again. | Google의 모델 (Nano Banana, Veo 3.1) <br />의 가이드라인에 위반할 경우 발생하는 에러입니다. |
| Failed to generate image. | Google의 모델 (Nano Banana) <br />의 가이드라인에 위반할 경우 발생하는 에러입니다. |
